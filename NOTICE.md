## Modifications

This fork modifies the upstream project to:

- Reorganize information architecture for mobile (less nesting, more scrolling, fuzzy search).
- Add a GM-side encounter YAML import (paste → run live in the director).
- Add a Claude skill (`skills/encounter-builder/`) that produces encounter YAML.

See the git history on branch `damascus/main` for the full diff against upstream `main`.
